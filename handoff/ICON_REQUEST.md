# 아이콘 디자인 요청서 (이모지 → 이미지 교체)

> 작성일: 2026-11-04 / 대상: 시스템팀 Work Hub (https://jungku3135.github.io/work-hub/)
> 목적: 화면 곳곳에 쓰인 **이모지를 전용 아이콘 이미지로 교체**한다. 이모지는 OS/브라우저마다 모양이 달라 리디자인(차분한 연회색 톤, 검정+주황 포인트, 둥근 알약 UI)과 어울리지 않는다.

## 1. 전달 방식
- **형식: SVG 권장** (PNG만 가능하면 96×96 이상, 투명 배경).
- 전달 위치: `handoff/icons/` 에 아래 "파일명" 그대로 넣어 주세요. 받으면 개발 쪽에서 적용합니다.
- 색: **단색, `currentColor`로 칠할 수 있게** (fill/stroke에 색 고정 금지). 그래야 라이트/다크 모드와 버튼 상태(검정 버튼 위 흰색 등)에 자동으로 맞춰집니다. 다색 아이콘이 꼭 필요하면 알려 주세요.
- 격자: 24×24 viewBox, 선 두께 1.75px, 끝 둥글게(round cap/join). 한 세트 안에서 선 두께·모서리 둥글기 통일.
- 표시 크기: 대부분 16~20px, 상단 로고만 24px. 작게 봐도 구분되어야 합니다.

## 2. 디자인 방향
- 참고: https://gettakecontrol.app/en/ (미니멀, 기하학적, 부드러운 둥근 모서리). 팔레트: 바탕 연회색 `#e9e9e7`, 글자/주 버튼 검정 `#121211`, 포인트 주황 `#ff7b4b`.
- 장식적·귀여운 느낌보다 **정보를 돕는 심플한 라인 아이콘**.
- 현재 화면 예시: `handoff/images/current-utility-menu.png` (유틸리티 메뉴의 🔗, ↗ 등이 이모지/문자로 표시된 상태).

### 3-1. 날씨 아이콘 (대시보드 상단 위젯, 현재는 CSS로 그린 애니메이션)
현재 위치: 대시보드 맨 위 시계 옆 "안산 · 구름 조금" 위젯의 52×52px 아이콘. 날씨 상태(코드→분류)와 낮/밤에 따라 바뀝니다.

| 파일명(제안) | 날씨 | 비고 |
|---|---|---|
| `weather-clear-day.svg` | 맑음(낮) | 해 |
| `weather-clear-night.svg` | 맑음(밤) | 달 |
| `weather-partly-cloudy-day.svg` | 구름 조금(낮) | 해 + 구름 |
| `weather-partly-cloudy-night.svg` | 구름 조금(밤) | 달 + 구름 |
| `weather-cloudy.svg` | 흐림 | 구름 2겹 |
| `weather-fog.svg` | 안개 | 가로줄 |
| `weather-rain.svg` | 비 | 구름 + 빗줄기 |
| `weather-snow.svg` | 눈 | 구름 + 눈송이 |
| `weather-thunder.svg` | 천둥번개 | 어두운 구름 + 번개 |

- 이 9개는 **다색 허용**(해=주황/노랑 계열, 비=파랑 등)이지만 위 팔레트와 어울리는 절제된 색으로. 라이트/다크 배경 모두에서 보여야 합니다.
- 지금은 해 광선 깜빡임, 구름 좌우 이동, 빗줄기/눈 떨어짐, 번개 번쩍임 같은 **움직임**이 있습니다. 움직임을 유지하려면 SVG 안에서 움직일 부분(광선, 구름, 빗방울, 눈송이, 번개)을 **그룹(`<g id="rays">`, `id="cloud"`, `id="drops"` 등)으로 나눠** 주세요. 그러면 개발 쪽에서 CSS로 애니메이션을 입힙니다. 정지 이미지만 주셔도 됩니다.

## 4. 교체하지 않는 것 (참고)
- **브라우저/OS 알림 제목**의 ⏰ — 시스템 알림은 이미지를 쓸 수 없어 문자 유지.
- Notion에 저장된 옛 회의록 제목("📌 안건" 등)을 읽어들이는 호환 코드는 **데이터 매칭용이라 이모지를 그대로 둠** (화면에는 보이지 않음).
- 업무일지 "完"(완료 표시)은 한자 문자라 대상 아님.

## 5. 개발 쪽 적용 계획 (디자이너는 신경 안 써도 됨)
- 아이콘 파일은 `icons/`에 두고 CSS `mask-image` 방식으로 입혀 글자색(`currentColor`)을 따라가게 한다 → 다크모드·버튼 상태 자동 대응.
- 문자열 안에 섞인 이모지(예: `"🏢 휴일 근무"`)는 `<span class="icon icon-office"></span> 휴일 근무` 형태로 교체.
- 이미지/PDF 저장(오프스크린 렌더링)에서도 아이콘이 나오도록 SVG를 인라인/데이터 URI로 불러와야 하는 항목(체크박스 등)은 별도 처리.
